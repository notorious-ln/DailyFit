```mermaid
sequenceDiagram
actor User as Пользователь
participant FE as Frontend
participant Rec as Recommendation Service
participant Plan as Plan Service
participant DB as Database
participant Log as Journal Service



User->>FE: Отмечает пункты / принимает всё / отклоняет
FE->>Rec: POST /recommendations/{id}/decide {action, selectedItems}
alt Отклонить
    Rec->>DB: Статус = «отклонена»
    Rec->>Log: «отклонение рекомендации»
    Rec-->>FE: OK
else Принять (все или отмеченные)
    Rec->>DB: BEGIN TRANSACTION
    Rec->>Plan: Применить изменения только к будущим задачам
    Note over Plan: Прошедшие дни и уже поставленные отметки не трогаем
    Plan->>DB: Обновить активный план
    Rec->>DB: Статус = «принята» / «частично принята»
    Rec->>Log: «принятие рекомендации»
    Rec->>DB: COMMIT
    alt Ошибка
        Rec->>DB: ROLLBACK
        Rec-->>FE: Ошибка, статус не изменён
    else Успех
        Rec-->>FE: OK
    end
end
FE-->>User: Обновить экран (план изменён или нет)
```
