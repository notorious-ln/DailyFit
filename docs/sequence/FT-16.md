# FT-16. Администрирование шаблонов

Роль администратора позволяет создать шаблон, изменить его и скрыть из каталога.

Изменение шаблона не меняет активные копии, которые пользователи уже ведут: у копии плана остаются свои название, уровень и описание, сохранённые при активации.

Администратор не получает ленту чужих комментариев дневника в первой версии.

Отчёт за период открывается на экране и не требует отдельного офисного пакета: сервер отдаёт данные для экрана и не формирует файл.

Запрос без токена получает 401. Запрос без роли admin получает 403.

```mermaid
sequenceDiagram
    actor Admin as Администратор
    participant FE as Frontend
    participant AdminSvc as Admin Service
    participant DB as Database
    participant Log as Journal Service

    Admin->>FE: Открывает список шаблонов
    FE->>AdminSvc: GET /admin/templates
    AdminSvc->>AdminSvc: Проверить роль admin

    alt Нет роли admin
        AdminSvc-->>FE: 403 Доступ запрещён
        FE-->>Admin: Ошибка доступа
    else Роль admin подтверждена
        AdminSvc->>DB: Получить все шаблоны, включая скрытые
        AdminSvc-->>FE: Список шаблонов
        FE-->>Admin: Показать каталог шаблонов

        Admin->>FE: Создаёт шаблон
        FE->>AdminSvc: POST /admin/templates
        AdminSvc->>DB: Сохранить новый шаблон
        AdminSvc->>Log: Записать создание шаблона
        AdminSvc-->>FE: 201 Шаблон создан

        Admin->>FE: Изменяет шаблон
        FE->>AdminSvc: PUT /admin/templates
        AdminSvc->>DB: Обновить только запись шаблона
        Note over AdminSvc,DB: Активные копии в active_plans не меняются
        AdminSvc->>Log: Записать изменение шаблона
        AdminSvc-->>FE: Шаблон сохранён

        Admin->>FE: Скрывает шаблон из каталога
        FE->>AdminSvc: PATCH /admin/templates/{id}/hide
        AdminSvc->>DB: Пометить шаблон is_visible = false
        Note over AdminSvc,DB: Уже активированные копии остаются в планах
        AdminSvc->>Log: Записать скрытие шаблона
        AdminSvc-->>FE: Шаблон скрыт
        FE-->>Admin: Каталог обновлён
    end

    Note over AdminSvc: Лента чужих комментариев дневника не отдаётся
```
