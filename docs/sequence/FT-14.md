# FT-14. Работа без облачного помощника

В настройках профиля облачный помощник выключается (`cloud_assistant_enabled = false`).

Планы, отметки задач и процент соблюдения продолжают работать без внешней модели.

Остаются правильные подсказки:

- если процент тренировок за семь дней ниже 50 и пропущены не менее двух занятий — предлагается облегчить неделю;
- если три недели подряд процент тренировок выше 90 и самочувствие отмечено как «легко» — предлагается небольшое усложнение.

Правильная подсказка проходит те же границы и то же подтверждение, что и ответ модели: лимит объёма 15%, запрет усложнения при двух и более пропусках за семь дней, статус черновика и `POST /recommendations/{id}/decide`.

```mermaid
sequenceDiagram
    actor User as Пользователь
    participant FE as Frontend
    participant Profile as Profile Service
    participant Assistant as Assistant Service
    participant Rules as Rules Engine
    participant Rec as Recommendation Service
    participant DB as Database

    User->>FE: Выключает облачный помощник
    FE->>Profile: PUT /profile {cloud_assistant_enabled: false}
    Profile->>DB: Сохранить настройку
    Profile-->>FE: OK

    User->>FE: Разобрать день или неделю
    FE->>Assistant: POST /analyze
    Assistant->>DB: Проверить cloud_assistant_enabled
    Note over Assistant: Облачный помощник выключен — LLM не вызывается
    Assistant->>DB: Сводка задач, дневника и трёх недель тренировок
    Assistant->>Rules: Правиловый комментарий и черновики
    Note over Rules: Ниже 50% и 2+ пропуска — облегчить. Три недели выше 90 и «легко» — усложнить
    Rules->>Rules: Те же границы, что у ответа модели
    alt Есть допустимые пункты
        Assistant->>DB: Recommendation status draft, source rules
        Assistant-->>FE: Комментарий и пункты
    else Пунктов нет
        Assistant-->>FE: Только комментарий
    end

    User->>FE: Принимает или отклоняет
    FE->>Rec: POST /recommendations/{id}/decide
    Note over Rec: То же подтверждение, что для ответа модели
```
